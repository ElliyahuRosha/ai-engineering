# Machine Learning From Scratch

This directory is a growing collection of small, focused Jupyter notebook
proofs of concept for learning classical machine-learning concepts from first
principles.

Each notebook will focus on one concept, implement or demonstrate it clearly,
and stay small enough to study independently. Notebooks will be added gradually
as the learning journey progresses.

## Planned shape

```text
ml-from-scratch/
├── README.md
└── <small concept notebook>.ipynb
```

No result or concept is presented as completed until its notebook exists and
has been run and reviewed.
